# Preliminary YOLO Experiments

This folder contains initial experiments conducted while exploring YOLO object detection and dataset preparation.

## Scripts

- `prepare_person_dataset.py` - Prepares a person-only dataset from COCO128 annotations.
- `train_test.py` - Tests YOLO11n training using the COCO128 example dataset.

## Purpose

These experiments were used to verify dataset preparation and YOLO training functionality before developing the large-image SAHI pipeline.

## Note

These scripts are preliminary experiments and are separate from the current DIV2K large-image processing workflow.
